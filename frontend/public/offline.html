พร้อมแม้ออฟไลน์

ดูข้อมูลที่เลือกเก็บและเตรียมร่างรายการ เมื่อออนไลน์จึงส่งให้ทวนและพิมพ์ยืนยัน ยอดเงินจริงจะไม่เปลี่ยนอัตโนมัติ

ปลดล็อกข้อมูลบนเครื่อง

ใช้รหัสออฟไลน์ที่ตั้งไว้ในหน้าตั้งค่า รหัสนี้ใช้ปลดล็อกบนเครื่องเท่านั้น

ยังไม่ได้เก็บข้อมูลบนเครื่อง กลับเข้าสู่ระบบ → ตั้งค่า → ติดตั้งแอปและออฟไลน์

ข้อมูลเป็นภาพ ณ เวลาที่เก็บ ไม่ใช่ยอดปัจจุบัน ไม่เก็บรูปสลิป แชท หรือ API key ร่างและข้อมูลจะถูกล้างเมื่อออกจากระบบ
